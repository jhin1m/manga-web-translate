Dev prebundle (`node_modules/.vite/deps`): one shared chunk `lib-*.js` holds Konva (single `_injectGlobal` def+call). Not a 6ca2388 regression (parity spec predates it: d357aeb).

- Nothing changed; dist not tracked.

## Task B - ShantellSans-Variable
Root cause: font has fvar wght 300..800, default 300. Browser FontFace applies CSS weight 400 to the wght axis; Pillow uses file default (300) => advance mismatch (2px). Baloo2/Lexend variable defaults are 400, so they pass.
Fix: fontTools instancer `wght=300 INFM=0 BNCE=0 SPAC=0` -> static file (1,284,736 -> 401,324 bytes) replacing `worker/fonts/` and `apps/web/public/fonts/` copies (id/filename/manifest unchanged; manifest regenerated by font_glyph_check: no diff; `fonts:sync --check` ok). No licence file exists in repo for fonts.
Result: gate now includes the font: 123 lines, 41 exact, max 1px, 0 over threshold. Worker export unchanged (it already rendered wght=300); editor preview of this font becomes Light(300) instead of Regular(400) - the weight exports always had.
Fixture note: boxes are assigned fonts round-robin, so re-adding the font reshuffled font assignment across 11 of 17 pages (generated file, biome-formatted). EXCLUDED_FONTS now empty; doc updated (known gaps removed, static instance recipe).
