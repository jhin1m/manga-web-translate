# v0.5.0 — Sắp xếp, xem dạng danh sách, kiểm tra bản mới ngay

## Có gì mới

- **Sắp xếp danh sách.** Trang chủ có ô **Sắp xếp theo** cạnh ô tìm: Hoạt động gần nhất, Tên, Ngày tạo, Số chương. Trang series xếp chương theo Số chương, Cập nhật hoặc Ngày tạo.
  - Nút bên cạnh đảo chiều xếp và ghi rõ đang xếp thế nào: "A→Z" / "Z→A", "Mới trước" / "Cũ trước", "Tăng dần" / "Giảm dần".
  - Tên so theo tiếng Việt, không phân biệt hoa thường. Số trong tên so như số ("Ch 2" đứng trước "Ch 10"), số chương lẻ như 10.5 cũng đúng chỗ.
  - Ô tìm series vẫn dùng chung được với sắp xếp.
- **Xem dạng danh sách.** Cặp icon **Lưới / Danh sách** ở cả hai trang. Dạng danh sách giống bản trước 0.4.0: mỗi series hay chương là một hàng, không có ảnh, vẫn có trạng thái, số chương hoặc thời gian, icon Sửa / Xoá. Xoá vẫn hỏi xác nhận ngay dưới hàng; thả lại file vào hàng chương upload dở vẫn tải tiếp; chương đang dịch có vạch tiến độ mỏng dưới hàng.
- **Trình duyệt nhớ lựa chọn.** Trang chủ và trang series nhớ riêng cách xếp và kiểu xem, tải lại trang vẫn giữ. Lần đầu mở vẫn là lưới với thứ tự như trước (series hoạt động gần nhất lên đầu, chương theo số tăng dần).
- **Kiểm tra bản mới ngay.** Menu avatar có mục **Kiểm tra bản mới**: hỏi GitHub luôn thay vì chờ tối đa 24 giờ, rồi báo app đã là bản mới nhất hoặc hiện **Có bản mới** như trước. Bấm dồn trong 30 giây chỉ trả lại kết quả vừa hỏi.

## Cách cập nhật

Từ 0.3.0 trở lên: bấm **Cập nhật ngay** trong menu avatar (khi bản 0.5.0 đã phát hành; bản 0.4.0 chưa có mục Kiểm tra bản mới thì chờ tối đa 24 giờ hoặc khởi động lại container `app`). Hoặc làm tay, chạy trong thư mục chứa `docker-compose.yml`.

**Windows (PowerShell):** gõ đúng `curl.exe` và chạy từng dòng một.

```powershell
curl.exe -fsSLO https://raw.githubusercontent.com/jhin1m/manga-web-translate/main/docker-compose.yml
docker compose pull
docker compose up -d
docker compose ps
```

**Linux / macOS:**

```bash
curl -fsSLO https://raw.githubusercontent.com/jhin1m/manga-web-translate/main/docker-compose.yml
docker compose pull && docker compose up -d
docker compose ps
```

- Không có migration mới, không có biến môi trường mới.
- Kiểm tra đã lên bản mới: mở menu avatar, dòng cuối phải là `MTL v0.5.0`.
- Không có thay đổi ở worker: worker 0.4.0 vẫn chạy với app 0.5.0.

## Giới hạn đã biết

- Lựa chọn xếp và kiểu xem lưu trong trình duyệt, không theo tài khoản: đổi trình duyệt, đổi máy hoặc dùng cửa sổ ẩn danh thì về mặc định.
- Chưa xếp được theo trạng thái (vd chương lỗi lên đầu) và chưa kéo thả để tự xếp.

## Kỹ thuật

- Sắp xếp làm ở web trên danh sách API đã trả đủ; API danh sách series / chương không đổi.
- `GET /api/admin/update?fresh=1` bỏ qua cache 24 giờ, tối đa 1 lần hỏi GitHub mỗi 30 giây.
- Khoá localStorage mới: `mtl.list.series`, `mtl.list.chapters` (`{ view, sort, dir }`; giá trị lạ thì dùng mặc định).
